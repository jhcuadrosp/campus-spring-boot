# Sesión 06 — Documentación de APIs mediante OpenAPI y Swagger UI

Estado: planificación documental. Duración institucional: **210 minutos**.

## Problema empresarial y objetivo

Hacer verificable y explorable el contrato del catálogo.

## Prerrequisitos

Contrato REST de la sesión 05.

## Contenidos y límites

OpenAPI, Swagger UI, esquemas, ejemplos y documentación de respuestas.

No abordar todavía: JWT y políticas de acceso; no documentar funcionalidades inexistentes.

## Secuencia de trabajo

| Bloque | Minutos | Aplicación |
| --- | ---: | --- |
| Desarrollo conceptual | 150 | Explicación del tema, problema, análisis y diseño |
| Práctica | 60 | Demo con implementación, pruebas, depuración y mejora; labs en el tiempo sobrante |
| **Total** | **210** | |
